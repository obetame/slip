## release 页面出现两个「slip 0.2.0」的根因（已修）

现象：同一 tag 下出现一个 draft + 一个 published，资产重复。

**真正的因果链**（前面两次修都没修对，记录于此以免重犯）：

1. **删 tag 会把挂在它上面的已发布 release 降级为 draft**，时间戳能对上（删 tag 后十几秒 `updated_at` 变化、`draft` 变 true）。
2. `GET /releases/tags/<tag>` **永远不返回 draft** —— 对草稿一律 404。所以"按 tag 查是否存在"在重建 tag 之后必然误判为"还没有 release"。
3. 于是每次重建 tag 都 `gh release create` 再造一份 → 重复。

中间踩的两个次要坑：
- publish job 没有 `actions/checkout`，`gh` 没有 git remote，`gh release view` 直接报 `fatal: not a git repository` → 任何依赖 exit code 的 `if` 都会静默走错分支。需要显式 `GH_REPO: ${{ github.repository }}`。
- 只用 exit code 判断"不存在"，会把网络/权限错误也当成不存在。只认 404，其它一律中止。

最终实现（`.github/workflows/release.yml` publish 步骤）：
- 走 `GET /releases?per_page=100`（含 draft），按 `tag_name` 过滤，取最新一条
- 0 条 → create；1 条 → upload `--clobber` 再 `edit --draft=false`（顺带把被降级的 draft 重新发布）
- 多余的只删 draft，出现第二个 published 就报错停下，不自作主张删

验证：重建 tag 后 release id 保持不变（419008660），仍为 latest，6 个资产，无新增。

**结论：以后发布新版本，正常 push tag 即可；不要在已有 release 的情况下反复删/建 tag 来重跑**，真要重跑用 Actions 的 re-run。

本地：main 落后一条合并提交（#17，f5564dd），代理 502 挡住 `git fetch`；工作区干净，文件内容除该 workflow 外无差异。

## 接手 dsh 会话 session-d4717270 未完成的网格布局修复

上一轮在同一会话里做到一半就被上游 400 打断，留下半成品：布局按钮已挪进 nav、
`renderBoardGrid` 已改成“所有纸条进墙”，但墙还是 `flex-wrap` 的一行 + `.tile{width:50%}`，
文字卡片带 sticky 头在窄格子里挤成一团。用户的原话是“切换网格好像没有什么变化，只是增加了时间分组，
也没有两列瀑布墙”。

这次收尾的关键判断：

1. **瀑布墙必须是两列各自的 flex 栈**（`renderBoardGrid` 交替发牌到 `.wallcol`），
   不能用 `flex-wrap` 折行：折行会让左右两列互相拖高，短纸条下方留大洞。
   交替发牌还能保证最新一条在左上、阅读顺序仍是左右左右。
2. **文字/文件格子复用 `slipNode`**，只靠 CSS 收窄（去 margin、去边框、`position: static` 的头部、
   更小的按钮），这样复制/展开/编辑/删除在网格里全部可用，不必写第二套卡片。
3. **`.wall .sliphead` 必须 `flex-wrap: wrap`**：`.sliphead` 本身是 nowrap，在 195px 的格子里
   meta 会被操作按钮挤成“1...”，第四个按钮还会被 `overflow:hidden` 裁掉。这是截图才发现的。
4. **`setLayout` 要顺手 `paintNav()`**，否则切换后按钮文案不翻转（网格里还写着“网格”）。
5. 图片格子只放缩略图 + 时间说明，点图进 viewer，不带操作行，这是“小红书感”的来源。

验证手段（很值）：用 playwright-core + 已下载的 `chrome-mac-arm64/Google Chrome for Testing`
起真浏览器截图，`deviceScaleFactor: 2`，430×932 与 900×900 各一张。
**注意 slip 的静态资源是 `go:embed` 进二进制的，改 CSS 后必须重新 `go build` 再起服务，否则截图不变。**

回归保护：`tooling/features.mjs` 新增 “grid layout” 段（两列、每张都成 tile、文字进墙、
网格无 daysep、nav 文案翻转 + 点回列表），`page()` 增加 `opts.layout` 以便在启动前写 localStorage。
