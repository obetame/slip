## 三个真实的坑（都是实测，不是猜测）

1. **environment 声明**：5 个签名 secret 在 `desktop-production` environment 上，job 不写
   `environment:` 就读到空值。PR #11（会话内已完成）。
2. **notarytool 只收 zip/pkg/dmg**，不能提交 tar.gz。zip 只是"信封"，提交完就删。
3. **裸 Mach-O 无法 staple**：`stapler` 只支持 UDIF 镜像/签名 bundle/flat 安装包。
   - 对 zip：`Stapler is incapable of working with Zip archive files.` exit 66
   - 对裸二进制：会真的去 CloudKit 查 cdhash，但必然 `Error 73`（票据生成了，无处存放）
   Apple DTS 明确说"tickets created for standalone binaries, not possible to staple"。
   Gatekeeper 首次运行联网取票据，属命令行工具的正常路径。
4. **spctl 的 -t exec 是陷阱**：macOS 26.3.1 上 `spctl -a -vvv -t exec /bin/ls` →
   `rejected (the code is valid but does not seem to be an app)`。exec 是 app bundle 策略；
   裸二进制要用 `-t install`，它才会返回 `source=Notarized Developer ID` / `Unnotarized Developer ID`。
